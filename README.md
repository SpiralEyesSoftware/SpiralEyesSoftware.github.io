# Spiral Eyes Software website

A static GitHub Pages-ready homepage based on the Spiral Eyes Software design mockup.

## Files

- `index.html` — page structure/content
- `styles.css` — responsive dark sci-fi styling
- `script.js` — mobile navigation, scroll highlighting, subtle hero motion
- `assets/spiral-eyes-hero.png` — the supplied Spiral Eyes hero artwork

## Deploy to GitHub Pages

1. Put these files in the repository used by `spiraleyessoftware.github.io`.
2. Commit and push to the configured Pages branch.
3. In GitHub, confirm Pages is serving the repository root.

The page has no build step and no JavaScript framework dependency.
